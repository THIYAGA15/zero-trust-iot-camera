 🛡️ Zero-Trust IoT Surveillance Camera & SOC Incident Response System

An end-to-end IoT Cybersecurity & SOC Automation project combining a **3D Hardware Digital Twin (ESP32)** with a **Python Live Camera AES Encryption Server, Automated Brute-Force Quarantine, and Real-Time SIEM/SMTP Alerting**.

## 📌 Project Architecture

### Phase 1: Hardware Digital Twin & Physical Tamper Defense
* **Microcontroller & Sensors:** ESP32 DevKit V1, ArduCAM, PIR Motion/Tamper Sensor, Status LEDs, and Passive Buzzer.
* **Security Logic:** Token-based authentication, physical tamper/intrusion alarm trigger, and structured JSON security event telemetry.

### Phase 2: Production Camera Encryption & Automated SOC Response
* **Encrypted Video Stream (`camera_server.py`):** Captures live frames via OpenCV and encrypts payloads using **AES-CBC-HMAC-SHA256 (`Fernet`)** over Flask API.
* **Automated Brute-Force Defense:** Tracks failed authentication attempts per IP and automatically quarantines attackers (`HTTP 403`) after 3 invalid attempts.
* **SIEM Logging & Incident Alerting:** Logs structured JSON events into `soc_camera_alerts.log` (Splunk/ELK ready) and sends real-time SMTP email alerts to the SOC analyst.

1. Install dependencies: `pip install opencv-python flask cryptography requests`
2. Start the Zero-Trust Camera Server: `python camera_server.py`
3. Run the Attack & Viewer Simulation: `python test_attack_and_viewer.py`
